Папка для ручной загрузки JSON-отчётов по работе системы модерации.

Назначение:
- анализ поведения текущей версии;
- разбор ложных срабатываний;
- разбор пропусков;
- доработка prompt, сигналов и логики накопительного риска.

Куда складывать файлы:
- `analysis/moderation_reports/incoming/`

Что желательно передавать:
- JSON-отчёты по отдельным инцидентам;
- выгрузки спорных диалогов;
- примеры ложных срабатываний;
- примеры пропусков угроз;
- отчёты после изменения модели/prompt.

Рекомендации по именованию:
- `YYYY-MM-DD_chat_<chat_id>_user_<user_id>_case_<short-tag>.json`
- `YYYY-MM-DD_batch_<short-tag>.json`

Важно:
- это папка для офлайн-анализа в репозитории;
- не использовать её как runtime-хранилище сервера;
- не смешивать с `HarborSentinel.Bot/data/`.
